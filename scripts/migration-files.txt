# Format: CLASS /absolute/path

# Classes:
# A - safe candidate: service configuration; may be proposed for migration
#     after content comparison and target backup.
# B - requires review: version-, service-, or system-dependent configuration;
#     report only unless explicitly approved.
# C - sensitive system configuration: network, SSH, access, or device identity;
#     never overwrite automatically.
# D - do not migrate automatically: secrets, runtime state, queues, databases,
#     cache, or application data; handle separately.
#
# Only paths listed below are read from either system.
# To migrate a complete directory, add its path with a trailing slash. Its
# regular files are then added individually to the report and migration plan.
