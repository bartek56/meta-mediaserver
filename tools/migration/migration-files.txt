# Format: CLASS /absolute/path
#
# Classes:
# A - directory/file may be migrated after comparison.
# A! - opaque directory: do not analyze files inside; package the complete
#      directory as one tar.gz, including hidden files, and replace the target
#      directory during --apply.
#     For a directory, the migration unit is the whole tar.gz archive.
# B - directory/file is validated and reported, but never copied automatically.
# C - directory/file is validated and reported, but never copied automatically;
#     typically network, SSH, access, or device identity.
# D - for a directory, verify every contained file and write the separate
#     directory-files.tsv report; never copy. For a file, report only.
#
# Only paths listed below are read from either system.
# To migrate a complete directory with normal per-file analysis, add its path
# with a trailing slash. For a ready-made opaque package without analyzing its
# contents, use A! instead.
